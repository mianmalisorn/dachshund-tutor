# CatTutor for dachshund tutor

Персональная веб-платформа для организации работы репетитора и взаимодействия с учениками.
CatTutor объединяет расписание, видеозанятия, домашние задания, учебные материалы, тестирование и аналитику в одном интерфейсе.
Проект создавался под реальные задачи преподавателя. Основной акцент сделан на удобстве повседневной работы, понятной навигации и минимальном количестве лишних действий.

## Возможности

**Рабочее пространство преподавателя:**
- Управление учениками и их учебными данными.
- Расписание занятий и планирование встреч.
- Домашние задания, материалы и отслеживание выполнения.
- Создание и проведение тестов, просмотр результатов.
- Учебная аналитика и отслеживание прогресса.
- Финансовый учёт.
- Уведомления и интеграция с Telegram.

**Взаимодействие с учениками:**
- Личный кабинет ученика.
- Видеозанятия через LiveKit Cloud.
- Демонстрация экрана.
- Чат во время занятия.
- Обмен учебными материалами.
- Доступ к заданиям и результатам.

## Технологии

* Backend - Python, FastAPI
* Frontend - Jinja2, HTML, CSS, JavaScript
* База данных - SQLite, SQLAlchemy
* Миграции - Alembic
* Видеосвязь - LiveKit Cloud
* Интеграции - Telegram Bot API
* Тестирование - pytest, браузерные E2E-тесты
* Развертывание - Docker, Amvera
